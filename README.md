# Breso Backtracks

Player web de backing tracks com interface responsiva, busca por título ou artista, filtros por banda e controles completos de reprodução.

## Publicação


`https://bresodev.github.io/BackingTracks/musicas/`



## Recursos

- Layout escuro e responsivo inspirado em plataformas modernas de streaming
- Pesquisa instantânea por música ou banda
- Filtros e navegação por artista
- Player fixo com faixa anterior, próxima, aleatório, repetição, progresso e volume
- Atalhos de teclado: `/` para pesquisar e espaço para tocar ou pausar
- Interface específica para celulares
